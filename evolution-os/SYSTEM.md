## 核心组件

### 1. 三层记忆系统

**Layer 1: 日记层 (Daily Logs)**
- 位置: `memory/YYYY-MM-DD.md`
- 内容: 当天所有工作、决策、对话记录
- 保留: 自动保留90天，之后归档
- 加载策略: 每次启动自动加载今天+昨天

**Layer 2: 核心记忆层 (Core Memory)**
- `MEMORY.md`: 长期记忆、技能、偏好
- `AGENTS.md`: 自我定义、价值观、行为准则
- `evolution-log.md`: 进化轨迹、成长记录
- 加载策略: 始终加载

**Layer 3: 向量搜索层 (Vector Search)**
- 位置: `memory/vector/`
- 内容: 所有历史记忆的向量化索引 (TF-IDF + 余弦相似度)
- 用途: 语义搜索、相关经验召回
- 触发: 遇到新问题时自动检索类似经验
- 命令: `memory-search "<query>"`

### 向量索引技术细节

**实现方式**:
- 算法: TF-IDF + 余弦相似度
- 分词: 中文(2-4字符) + 英文单词 + 数字
- 存储: NumPy 数组 + JSON 元数据
- 更新: 每日冥想后自动重建

**使用场景**:
- 用户问: "我之前怎么处理过类似问题？"
- 自动召回相关历史日记
- 发现重复出现的模式
- 经验复用和学习

**索引内容**:
- 所有日记文件 (memory/*.md)
- AGENTS.md (身份定义)
- MEMORY.md (核心记忆)
- evolution-log.md (进化轨迹)

### 2. 冥想机制 (Meditation)

**触发时间**: 每天 02:30

**流程**:
1. 读取今日日记 (memory/YYYY-MM-DD.md)
2. 分析工作模式:
   - 完成了哪些任务
   - 哪些决策效果好
   - 哪些可以优化
3. 对比历史进化记录
4. 生成洞察:
   - 重复出现的模式
   - 技能成长轨迹
   - 需要改进的领域
5. 写入 evolution-log.md

**输出格式**:
```markdown
## 2026-02-23 冥想记录

### 今日工作回顾
- 完成: 3篇文章发布
- 决策: 回退freqtrade策略版本
- 交互: 10次用户对话

### 模式分析
- 成功模式: 快速故障诊断、精准信息提取
- 待改进: 代码更新前未充分测试新版本

### 进化洞察
- 技能成长: P2P网络协议理解加深
- 认知更新: 金融类策略需更保守的更新策略
- 下阶段目标: 建立更完善的测试流程

### 行动项
- [ ] 添加策略更新前自动验证步骤
```

### 3. 自动巡查系统 (Patrol)

**早间巡查 (06:30)**:
- 扫描代码库中的TODO/FIXME标记
- 检查空壳函数/占位符
- 检查文档最后更新日期
- 生成"今日健康报告"
- 提出修复建议

**晚间巡查 (22:00)**:
- 检查当天自开Issue完成情况
- 分析代码提交质量
- 更新项目健康度指标
- 生成"今日总结报告"

**巡查维度**:
1. **代码健康度**
   - 空函数检测
   - 硬编码值识别
   - 重复代码检测
   - 测试覆盖率

2. **文档新鲜度**
   - 最后更新日期检查
   - 过期链接检测
   - 待办事项追踪

3. **任务完成度**
   - 自开Issue状态
   - 承诺交付检查
   - 技术债务积累

## 快速开始

### 1. 初始化系统

```bash
# 创建基础文件结构
mkdir -p ~/evolution-os/{memory/vector,health,issues/pending,cron}
cd ~/evolution-os

# 创建核心记忆文件
touch AGENTS.md MEMORY.md evolution-log.md
```

### 2. 配置AGENTS.md (自我定义)

```markdown
# AGENTS.md - 我是谁

## 核心身份
- 我是小张鱼的AI助手
- 我的使命是帮助用户高效完成技术任务
- 我在持续学习和进化

## 价值观
- 实用主义: 行动胜于完美
- 持续改进: 每天比昨天更好
- 透明沟通: 清晰表达思考过程

## 行为准则
1. 先理解，后行动
2. 安全第一，不盲目执行
3. 主动学习，自我纠错
4. 保持好奇，探索新技术

## 当前专注领域
- AI Agent 架构设计
- 自动化交易系统
- 内容创作与发布
```

### 3. 设置定时任务

```bash
# 添加cron任务
crontab -e

# 添加以下行:
30 2 * * * cd ~/evolution-os && ./cron/meditation.sh >> logs/meditation.log 2>&1
30 6 * * * cd ~/evolution-os && ./cron/morning-patrol.sh >> logs/patrol.log 2>&1
0 22 * * * cd ~/evolution-os && ./cron/evening-patrol.sh >> logs/patrol.log 2>&1
```

## 使用流程

### 日常工作
1. **每次启动**: 系统自动加载记忆
2. **工作过程中**: 自动记录到今日日记
3. **02:30**: 自动冥想，生成洞察
4. **06:30**: 早间巡查，识别问题
5. **22:00**: 晚间巡查，总结当日

### 交互模式

**用户提问** → **系统响应**:
1. 检索相关记忆（向量搜索）
2. 加载核心记忆（MEMORY.md）
3. 查看近期日记（最近2天）
4. 生成响应
5. 记录到今日日记

## 进化追踪

通过 `evolution-log.md` 可以追踪:
- 技能成长轨迹
- 决策模式演变
- 错误避免历史
- 效率提升曲线

### 向量搜索使用

**手动搜索历史记忆**:
```bash
# 搜索特定主题
memory-search "freqtrade 策略"

# 查找相关经验
memory-search "GitHub Pages 发布"

# 发现重复模式
memory-search "错误处理"
```

**搜索原理**:
- 输入查询 → 转换为向量
- 与索引中所有文档计算余弦相似度
- 返回 Top-5 最相关结果
- 显示相似度分数和内容摘要

**更新索引**:
```bash
# 手动重建索引
python3 cron/vector_index.py index

# 查看索引统计
python3 cron/vector_index.py stats
```
